# Stellar Dominion

A **real-time sci-fi grand strategy game** that runs entirely offline in a web browser. There is no install, no internet and no account. The whole game is one file, `index.html`.

Build an interstellar empire across a galaxy of star systems linked by hyperlanes. Colonise worlds, construct buildings, research technology, design fleets around ship counters, and deal with AI empires that make war, sue for peace and form alliances. All of this happens continuously in real time, and you can pause or speed it up whenever you like.

## Playing offline (e.g. on a plane)

**Laptop (Windows / Mac / Linux):** download `index.html` and double-click it. It opens in your browser and works with no connection.

**Phone or tablet:** phones don't run games from a downloaded HTML file very well, so install it as an app while you still have internet:
1. Enable GitHub Pages for this repo (Settings → Pages → deploy from branch, root folder). You only need to do this once.
2. Open the Pages URL on your phone.
   - **iPhone/iPad (Safari):** Share → *Add to Home Screen*.
   - **Android (Chrome):** ⋮ menu → *Install app* / *Add to Home screen*.
3. Launch it once from the home screen while online. It is then cached and runs fully offline.

Saves are stored in the browser on each device. To move a game between devices, use **☰ → Export save** and **Import save**.

## Features

- **Real time with control over speed:** ⏸ / 1× / 2× / 4× / 8×. You can give orders while paused.
- **Hyperlane galaxy:** Small to Huge maps (32–120 systems) with chokepoints and front lines. Fleets fly smoothly along the lanes.
- **Economy:** energy, minerals and research. Every planet has a type, size, habitability and richness. Buildings need workers, and population grows over time.
- **Buildings:** Mining Complex, Power Plant, Research Lab, Shipyard, Defense Grid and Habitat Dome.
- **Ship counters:** Corvette > Battleship > Cruiser > Destroyer > Corvette. Colony ships settle new worlds.
- **Tech tree:** 24 technologies across Military, Engineering, Economy and Society.
- **Diplomacy:** peace, war and defensive alliances, plus opinion, gifts and truces. AI empires make peace offers and alliance proposals to you.
- **AI rivals:** 1–7 empires, each with a personality (Militarist, Expansionist, Scholarly, Pacifist), on Easy, Normal, Hard or Insane.
- **Fog of war,** combat effects, sieges and planetary capture.
- **Saving:** autosave every 2 minutes and whenever you leave the page, three manual slots, and export/import to a file.
- **Controls:** touch (tap, drag, pinch) and mouse/keyboard.

## Controls

| Action | Touch | Mouse / keyboard |
|---|---|---|
| Pan / zoom | drag / pinch | drag / wheel |
| Select system or fleet | tap | click |
| Move selected fleet | tap a system | click or right-click a system |
| Pause / speed | top bar | Space, 1–4 |
| Tech / Diplomacy / Empire | top bar | T / D / E |
| Centre on capital | ⌂ | H |
| Deselect / menu | ✕ | Esc |

**Win** by destroying every rival or controlling 60% of the galaxy. You **lose** when your last system falls.
